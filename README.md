# Spotify Clone 🎵

This is a **Spotify Clone** project (Frontend only) built using HTML, CSS, and Font Awesome. It aims to replicate the basic UI of Spotify's web player with functionalities like a sidebar navigation menu, main content area with cards, and a fixed music player at the bottom.

## 🔍 Features
- Responsive Sidebar Navigation (Home, Search, Your Library)
- Trending and Recently Played sections
- Featured charts display
- Stylish music player bar (currently non-functional)

## 📂 Technologies Used
- HTML5
- CSS3
- Font Awesome (for icons)
- Google Fonts (Montserrat)
